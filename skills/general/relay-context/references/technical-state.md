# Technical Resume State

Capture the minimum technical state required to resume safely:

- Exact paths, URLs, identifiers, branches, revisions, commands, or configuration values.
- Relevant environment, connected services, permissions, credentials availability, and platform limitations without exposing secrets.
- Working-tree or artifact state, including staged, uncommitted, generated, or temporary work that could be overwritten.
- Tests, checks, builds, and their latest known results with evidence grade and timestamp when available.
- Interfaces, dependencies, data migrations, or integration state that constrain the next action.

Reference authoritative files, plans, ADRs, issues, diffs, and logs instead of copying them. Mark inaccessible, stale, or platform-specific references.

Keep commands ready to paste only when exact and safe. Never claim a command was run or a result reproduced without evidence. Identify the first technical verification the next agent should perform and any condition that must stop execution.
